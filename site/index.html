An encrypted drive in your Telegram chat

Telegram lets a bot store files in a chat for free. taasant turns that into a drive you use from the terminal, and encrypts every file before it leaves your computer.

What you get

A small tool that does one job: keep files in a chat only you can read.

Encrypted before upload

Every file is encrypted on your computer with AES-256-GCM. Telegram only ever stores scrambled bytes.

Big files, handled

Large files are split into parts, sent side by side, and put back together when you download.

Names, not IDs

Get a file back by name. Type part of it, or a few of its letters: taasant download hol finds holiday.jpg.

A menu or plain commands

Run taasant to browse folders and pick files with the arrow keys, or use the commands in scripts.

How it works

A bot can only download files up to 20 MB, so one big file becomes many small ones.

  1. Split

    The file is read in parts that stay under Telegram's limit.

  2. Encrypt

    Each part is sealed with your key. A wrong key or a changed byte is detected.

  3. Send

    Each part goes out as its own message, followed by a small encrypted list of the parts.

Using it

Setting up takes about five minutes: make a bot, find your chat ID, make a key.

taasant upload report.pdf     # store a file
taasant list                  # see everything, newest first
taasant download report       # get it back
taasant delete report         # remove it
taasant update                # get the newest version

taasant is a hobby project and runs on Telegram's goodwill. Be reasonable about what you store, and keep a copy of anything important somewhere else. If you lose your key, your files cannot be recovered.
