An encrypted drive in your Telegram chat

Telegram lets a bot store files in a chat for free. taasant turns that into an encrypted drive you use from the terminal: upload, list, download and delete by name.

Install taasant Set it up 
$ taasant upload holiday.jpg
✓ holiday.jpg  45.0 MiB  uploaded in 12.4s

$ taasant list
  NAME               SIZE   UPLOADED
  holiday.jpg    45.0 MiB   today 12:09
  report.pdf      1.2 MiB   yesterday
  notes.txt       4.0 KiB   3 Oct

  3 files, 46.2 MiB

$ taasant download hol
✓ saved holiday.jpg

What you get

Encrypted before upload

Every part is encrypted on your computer with AES-256-GCM. Telegram only ever sees scrambled bytes.

Big files, handled

Large files are split into parts and put back together for you. No manual chunking.

Names, not IDs

Get files back by name. Type part of it, or just a few of its letters.

A menu or commands

Run taasant in a folder to pick files with the arrow keys, or use one command per job. See Using taasant.

One small binary

Written in Go. Download it, run it, done.

What Telegram sees

Your chat holds files called part.bin. Without your key, they are noise.

You
holiday.jpg
45.0 MiB
JPEG image data,
1920 × 1080
Telegram
part.bin
19.0 MiB
9f3ab2c7e04d11a6
5be8d0731cf29a4e
e61b87d5a30c94f2
… (illustrative)

Opening a stored file from the Telegram app gets you nothing useful. Always use taasant download.

A tip before you start

Telegram might restrict a bot that is used this way. To be safe, make your bot from a second Telegram account, and keep a copy of anything important somewhere else. See Limits.

Install

Download a single binary for your platform. No Go toolchain needed unless you want to build from source.

On macOS or Linux, one command downloads the right file and puts it in /usr/local/bin:

bash
curl -fsSL https://taasant.vedantworks.com/install.sh | sh

Or do the same steps by hand:

bash
curl -L -o taasant https://github.com/vedantlavale/taasant/releases/latest/download/taasant-macos-arm64
chmod +x taasant
sudo mv taasant /usr/local/bin/
taasant keygen
bash
curl -L -o taasant https://github.com/vedantlavale/taasant/releases/latest/download/taasant-macos-intel
chmod +x taasant
sudo mv taasant /usr/local/bin/
taasant keygen
bash
curl -L -o taasant https://github.com/vedantlavale/taasant/releases/latest/download/taasant-linux-amd64
chmod +x taasant
sudo mv taasant /usr/local/bin/
taasant keygen

Download taasant-windows.exe from the releases page and run it from a terminal.

Requires Go 1.27 or newer.

bash
go install github.com/vedantlavale/taasant/cmd/taasant@latest

Or build it yourself:

bash
git clone https://github.com/vedantlavale/taasant.git
cd taasant
go build -o taasant ./cmd/taasant

If taasant keygen prints a long string of letters and numbers, the install worked.

“Apple could not verify taasant”

You will see this on a Mac if you download the file with your browser instead of curl. Nothing is wrong with the file. macOS shows it for any program whose author has not paid for an Apple developer certificate.

Click Done (not “Move to Bin”), then tell macOS you trust it:

bash
xattr -d com.apple.quarantine ~/Downloads/taasant-macos-arm64

Then carry on with the chmod and mv steps. You can also open System Settings → Privacy & Security and press Open Anyway.

Downloading with curl, as shown above, skips the warning entirely. Don't double-click the file: taasant is a terminal program and has no window.

Set it up

About five minutes, once. The first time you run taasant, it asks for what it needs and saves it.

Tip: use a second Telegram account

Telegram might restrict a bot that is used this way. To be safe, make the bot from a second account, not your main one.

  1. Run taasant

    bash
    taasant

    The first time, a setup screen opens. The menu comes after it.

  2. Make a bot and paste its token

    In Telegram, open a chat with @BotFather, send /newbot, and answer its two questions. It gives you a token that looks like 123456:ABC.... Paste it into taasant, which checks it with Telegram.

  3. Choose where the files go

    A private channel (recommended): create a private channel in Telegram, add your bot to it as an administrator, and post any message in it.

    The chat with the bot: open your bot in Telegram and press Start.

    taasant waits until it hears from that chat and asks if it is the right one. There is no chat ID to look up.

  4. Done

    taasant makes your encryption key, saves everything, and opens the menu.

The key is the only thing that can read your files

taasant makes the key for you and keeps it in its settings file. Put a copy of that file in your password manager. If you lose it, your files are gone for good. Nobody can recover them.

The setup screen is new in version 0.3. On an older version, run taasant update first.

Where the settings are kept

The bot token, the chat and the key are saved in one file that only your user account can read.

SystemSettings file
macOS~/Library/Application Support/taas/config.json
Linux~/.config/taas/config.json
Windows%AppData%\taas\config.json
AnywhereSet TAAS_CONFIG to use a path of your choice.

Environment variables

Every one is optional. One that is set wins over the settings file, which is useful in scripts. A setup made before version 0.3 with these three variables keeps working as it is.

VariableWhat it is
TG_BOT_TOKENToken from @BotFather.
TG_CHAT_IDThe number of the chat the bot stores files in.
TAAS_KEYThe encryption key, 64 hex characters. taasant keygen prints a new one.
TAAS_CONFIGWhere to keep the settings file.
TAAS_INDEXWhere to keep the index file. See What ends up where.
NO_COLORSet to 1 for plain text output in a terminal.

Commands

The same things, one command each. Use these in scripts, or when you already know the file's name.

bash
taasant upload report.pdf          # store a file
taasant list                       # see everything, newest first
taasant list rep                   # search
taasant download report            # get it back
taasant download report copy.pdf   # get it back under another name
taasant delete report              # remove it
taasant update                     # get the newest version of taasant

You don't have to type the whole name. See Finding files by name.

Progress

Uploads and downloads show a progress bar that moves as the bytes go out. If the connection drops, taasant tries again a few times before it gives up.

In scripts

When the output is not a terminal, taasant drops the colours and the progress bar. upload then prints only the file's ID, so you can capture it:

bash
id=$(taasant upload backup.tar)

Set NO_COLOR=1 if you want plain text in a terminal too.

It won't overwrite your files

If a file with that name already exists where you are, download stops with file exists. Give it a different output name, as in the copy.pdf example above.

Finding files by name

You don't have to type the whole name. taasant download hol finds holiday.jpg, and so does taasant download hjp.

Try it

Type into the box. This runs the same three-step match that taasant uses.

$ taasant download

The three steps

The first step that finds something wins.

  1. Exact name. holiday.jpg
  2. Part of the name, ignoring case. holi
  3. Fuzzy. The letters appear in that order, with anything in between. hjp matches holiday.jpg.
It never guesses

If more than one file matches, taasant shows you the matches and does nothing. It will never guess which file you meant to delete. A full ID always works, even for a file that is not in your index.

What ends up where

Your files live in Telegram. The list of what you uploaded lives on your computer.

In your Telegram chat

Your files, as messages with an attachment called part.bin. A small file is two messages: the file and a tiny list of its parts. A big one is several. They are encrypted, so opening one from the Telegram app gets you nothing useful.

On your computer

Your settings, in config.json (see Set it up), and a list of what you have uploaded, called the index. Both are in the same folder.

SystemIndex location
macOS~/Library/Application Support/taas/index.json
Linux~/.config/taas/index.json
AnywhereSet TAAS_INDEX to use a path of your choice.

A backup of that list

Every time you upload or delete, taasant also sends an encrypted copy of the index to your chat, and notes where it is in a file called index.json.remote next to the index. Each backup adds a couple of messages to the chat, so expect some clutter.

Look after the index

If you lose it, your files are still in the chat, but taasant no longer knows which messages are which. Copying the taas folder somewhere safe now and then is enough.

Limits

Worth knowing before you rely on it.

Lose the key, lose the files

The key is the only thing that can decrypt them. Keep a copy in a password manager.

Delete window

Telegram lets a bot delete messages for 48 hours after sending them. After that, taasant delete fails and you would have to remove the messages by hand in the app.

Memory

Files are handled in 19 MiB parts and several are in memory at once. A very large download can use a lot, because all its parts are fetched together.

One computer

The index is not synced. If you use taasant on two machines, each has its own list.

Telegram's terms

Under its bot developer terms, Telegram might restrict a bot that is used for storage. To be safe, make the bot from a second account, keep another copy of your files, and be reasonable about how much you store.

Troubleshooting

Find your error message below.

there is no bot token, run "taasant" in a terminal to set up

taasant has not been set up on this computer. Run taasant with nothing after it and answer its questions. See Set it up.

the bot can't send messages to the bot

Your TG_CHAT_ID is a bot's ID. This usually means you used the number at the start of the token. Use the number @userinfobot gave you.

bot can't initiate conversation with a user

The bot may not write to you until you have written to it. Open your bot in Telegram and press Start.

401 Unauthorized

The token is wrong or has been revoked. Get a fresh one from @BotFather.

cipher: message authentication failed

The key in use is not the key this file was uploaded with. Check whether TAAS_KEY is set and differs from the key in the settings file.

the key must be 64 hex characters

The key is missing or got cut off when it was pasted. If you set TAAS_KEY yourself, check it with echo $TAAS_KEY.

file exists

download won't overwrite. Give it another output name: taasant download report copy.pdf.

How it works

A bot can upload files up to 50 MB but can only download ones up to 20 MB. So taasant cuts every file into 19 MiB parts.

An upload

1. Read

The file is read in parts of 19 MiB, so every part can be downloaded later.

2. Split

The last part is whatever is left over.

3. Encrypt

Each part is sealed with AES-256-GCM. GCM also detects a wrong key or changed data.

4. Send

Each part goes out as its own message, then one more small encrypted file: the manifest, which lists the parts in order.

The manifest's ID is what gets saved in your index next to the file name.

A download

The reverse: look up the name, fetch the manifest, fetch the parts, decrypt them, and write them out in order.

A delete

Fetch the manifest, delete every part, then delete the manifest itself. The manifest goes last, so the list of parts is not lost if a delete fails halfway.
